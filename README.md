# Alankrit Singh — Portfolio

A responsive, single-page portfolio website built with HTML and CSS.

## Publish with GitHub Pages
1. Create a **public** repository named `alankrit123789.github.io` (GitHub Pages uses the exact account username; if GitHub rejects this name, use `portfolio` instead).
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then Save.
6. Wait for GitHub Pages to publish. The site URL will be `https://alankrit123789.github.io/` for the special username repository, or `https://alankrit123789.github.io/portfolio/` for a normal `portfolio` repository.

Review all details before publishing. The portfolio intentionally describes interests as learning areas and does not claim work experience or certifications.
